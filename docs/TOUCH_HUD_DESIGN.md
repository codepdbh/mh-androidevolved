# Diseño de controles

Los gráficos se generan con `tools/generate_touch_assets.py` y se validan con `tools/verify_touch_assets.py`. Las acciones son un catálogo preliminar y no se han contrastado con la configuración o el ejecutable; algunas pueden carecer de equivalente. Los iconos no emiten entrada. La aplicación solo carga imágenes en una galería de diagnóstico. Faltan motor multitáctil, zonas de cámara, estados mantenidos, cancelación, editor, persistencia y enlace con el runtime.
